VIDÉOS DU PORTFOLIO

Déposez vos fichiers vidéo MP4 dans ce dossier.
Pour une lecture fiable sur GitHub Pages, utilisez de préférence :
- conteneur MP4
- vidéo H.264
- audio AAC
- noms de fichiers simples, sans accents ni espaces

Exemple :
videos/realisation-01.mp4

Puis ajoutez un bloc .video-card dans index.html pour chaque nouvelle vidéo.
